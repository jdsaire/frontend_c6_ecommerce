# Grading Criteria (Reference Only)

This file records the capstone's peer-review grading breakdown and submission
questions, exactly as given in the assignment brief, for reference against the
final submission. **It does not answer them** — the actual submission is a
text-field response outside this repository, not a file checked in here.

## Grading Criteria Overview (18 Points Total)

| Points | Criterion |
|---|---|
| 2 | Did you identify three key features of your app? |
| 2 | Did you analyze the main challenges and describe solutions? |
| 4 | Did you explain how the front-end and back-end communicate, including state management and data handling? |
| 6 | Did you describe input validation, authentication, and other security measures? |
| 4 | Did you implement state management and performance optimizations? |

## Submission Questions

The peer-review submission answers these six questions in text-field entries
(no code, no GitHub repo link required as evidence):

1. Project Title
2. Describe your e-commerce app and its functionalities.
3. What were the major challenges you faced, and how did you overcome them?
4. How did you implement key components like business logic, UI/UX, and
   security?
5. What security measures did you implement?
6. How did you manage state and optimize performance?
